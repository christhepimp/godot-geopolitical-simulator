# Development Roadmap

## Phase 0 – Foundation (Current)
- [x] Repository + vision + architecture docs
- [ ] Godot 4 project scaffolding
- [ ] Basic high-altitude 3D camera + simple world mesh / heightmap
- [ ] Minimal dedicated server + client connection
- [ ] Player authentication / session skeleton

## Phase 1 – World & Nations
- [ ] Data-driven nation definition
- [ ] Basic government types + player ability to form / join nations
- [ ] Simple resource nodes on the map
- [ ] Territory / border visualization on the 3D map
- [ ] Basic time progression (1 real day = 1 in-game week)

## Phase 2 – Economy & Population (Simplified)
- [ ] Core resources + production chains
- [ ] Aggregated population model per region
- [ ] Simple GDP / tax / budget loop
- [ ] Basic trade between nations

## Phase 3 – Military & Conflict
- [ ] Unit types + logistics (fuel / ammo / supply)
- [ ] Strategic movement on the map
- [ ] Basic combat resolution
- [ ] War declaration / peace treaties

## Phase 4 – Diplomacy & Intelligence
- [ ] Embassies, treaties, alliances
- [ ] Simple espionage actions
- [ ] Public opinion / media influence (basic)

## Phase 5+ – Depth Expansion
- Science / research trees
- Deeper population (key NPCs with memory)
- Crime / black markets
- Environment & climate feedback
- Space layer
- Full multiplayer polish for 300 players
- Persistent world saves & server tools

---

This roadmap is intentionally flexible. The north star is a living world that keeps generating history rather than a finished “game”.
